# Tutorials

Practical, opinionated guides for full-stack developers. No fluff, no hello-world apps — just
the patterns I actually use in production.

## What's here

These guides assume you're a working developer who wants to build real products. I skip the
basics and focus on the decisions that actually matter.

### Start here

- [Dev Environment Setup](./setup) — The setup I use across all my projects

### Full-stack guides

- [Building a SaaS with Next.js](./nextjs-saas) — Auth, billing, teams, emails
- [Postgres Patterns for Developers](./postgres-patterns) — Schema design that scales without headaches
- [Deploy on a VPS (and stop paying Heroku prices)](./deploy-vps) — Hetzner + Dokku setup

## Format

Every tutorial has:

1. **What you'll build** — concrete, runnable outcome
2. **Why this approach** — the tradeoffs I considered
3. **The code** — copy-pasteable, production-ready
4. **What I'd do differently** — honest retrospective
